test04 @RestController와 @Controller 차이 / @RestController -> @Controller 변경 후 확인
@RestController : 반환값을 그대로 HTTP 응답 본문으로 보냄. 템플릿 사용하지 않음
@Controller : 반환값을 뷰 이름으로 해석하고 해당 이름의 템플릿을 찾아 렌더링함


spring-boot-starter-thymeleaf : 템플릿 엔진
- src/main/resources/templates 을 위치 자동설정해줌
- 템플릿 파일 확장자 기본 설정 .html
- 컨트롤러에서 index로 리턴하는 것을 ViewResolver를 자동구성해줌
- 컨트롤러에서 Model 객체를 통해 데이터를 뷰(HTML)로 전달할 수 있고 <th:> 태그를 지원함


test05: org.springframework.ui.Model 객체를 확인
  -> 컨트롤러에서 View(HTML) 데이터를 전달하기 위한 객체(웹페이지에서 동적으로 값을 표시할 때 전달용으로 사용)
  -> addAttribute(key, value);
@PathVariable(URL 경로 변수 바인딩)를 사용하여 값을 전달하는 과정 확인
  -> @RequestMapping("/{num}")
  public String index(@PathVariable int num, Model model){}
