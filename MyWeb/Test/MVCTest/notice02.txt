 API 요청 주소 정리

 GET http://localhost:3001/api/travels : 전체출력 getALL
 POST http://localhost:3001/api/travels : 입력 create
 GET http://localhost/api/travels/1 : 상세조회
 PUT http://localhost/api/travels/1 : UPDATE
 DELETE http://travels/1 : 삭제
