
1. DB 생성, 테이블 생성 -> 스키마 생성

2. backend/config/db.js -> 연결 객체 추가

3. 순서도
클라이언트 -> app.js -> travelRoutes[라우팅] -> travelController[로직(페이지)처리]
      -> travelMode[Dao] -> db.js(db.연결) -> DB[MysqlDB]

4. 서버 셋팅
$ cd backend
$ npm init -y

5. 플러그인 설치
$ npm install express cors mysql2

6. 실행 명령
node app.js
