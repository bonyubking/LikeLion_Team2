    Initializing Spring DispatcherServlet 'dispatcherServlet' : @RequestMapping("/")로

3. DispatcherServlet : 웹 요청을 처리하는 Spring의 Front Controller
   -> 톰캣이 사용자의 요청을 받으면 DispatcherServlet으로 전달된다. 
   -> @RequestMapping를 찾아서 컨트롤러에게 라우팅(전달)한다.
   *들어오는 모든 웹 요청을 가로채고, 어떤 컨트롤러가 요청을 처리해야할지 결정하고, 최동 응답을 사용자에게 보내는 역할을 한다.

 test04 : @RestController 와 @Controller 차이 / @RestController -> @Controller 변경 후 확인 
@RestController : 반환값을 그대로 HTTP 응답본문(JSON 등)으로 보낸다. 템플릿을 사용하지 않는다.
@Controller : 반환값을 뷰 이름(view name)으로 해석하고, 해당 이름의 템플릿을 찾아서 랜더링 한다. 
 
 @Controller // 현재 클래스는 웹 요청을 처리하는 컨트롤러 
public class DemoController {
	@RequestMapping("/") // "/"의 경로로 들어오는 요청을 처리
	String home() {
		return "index"; // src/main/resources/templates/index.html 템플릿 뷰를 찾아 랜더링한다. 
	}
}
