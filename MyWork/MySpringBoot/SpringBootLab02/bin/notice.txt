3. DispatcherServlet: 모든 요청의 진입점, 요청 위임과 흐름(Controller 매핑 ) 등 
    Controller에서 실행되는 값 전달 리턴, MVC 로직 흐름등을 관련한 정보 객체이며 실제 컨트롤러 실행을 해주는 객체이다.

4. /src/main/resources/templates/error.html -> Spring Boot에서 기본 error 페이지로 지정해서 사용된다
없을 경우는 위치에서 가상생성해서 리턴 / 명시하면 명시된 페이지로 매핑 

5. 커스텀 예외 처리 방법 
  1) [강력추천] @RestController -> @RestControllerAdvice 클래스에서 ResponseEntity 객체로 리턴하는 메소드를 예외 종류에 맞게 구현
  2) @Controller -> @ControllerAdvice 클래스에서 ModelAndView 객체로 리턴하는 메소드를 예외 종류에 맞게 구현
  
  3) [강력추천] @Controller등과 함께 ErrorController 인터페이스를 implements해서 사용자 예외 클래스로 선언한 후 이벤트로 핸들링
